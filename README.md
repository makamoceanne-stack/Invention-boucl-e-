# Invention Bouclée - Sécurisation et Gestion Logistique

> Projet L1 Informatique - UY1 - Administration Systèmes et Réseaux

### 🎯 Problématique
Comment protéger les données confidentielles d'une structure tout en gérant efficacement son matériel logistique pour éviter les vols et les pannes ?

### 💡 Solution : La boucle fermée
Mon système fonctionne en boucle :
1.  **Inventaire** -> Chaque matériel a un QR code
2.  **Traçabilité** -> On sait qui utilise quoi
3.  **Sécurisation** -> Données chiffrées (AES-256) + contrôle d'accès + 2FA
4.  **Sauvegarde Bouclée** -> Sauvegarde auto locale + cloud. Si l'un tombe, l'autre prend le relais.

### 🛠️ Technologies
- Linux / Windows Server
- Python (scripts d'automatisation)
- MySQL / Base de données
- Réseaux : Cisco, Pare-feu

### 🔒 Sécurité des données
- Chiffrement des fichiers confidentiels
- Gestion des droits utilisateurs
- Journaux d'accès (logs)

### 📦 Gestion logistique
- Tableau de bord temps réel du stock
- Alertes maintenance
- Historique des mouvements de matériel
